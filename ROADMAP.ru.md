# Roadmap — VortexDL

## В планах

*   [ ] **Поддержка YouTube:** Загрузка аудио и видео по ссылкам на треки, плейлисты или каналы.
*   [ ] **Нативное Android-приложение:** Плеер/клиент для Android, который сможет обращаться к вашему серверу VortexDL и выкачивать музыку на автомате без участия ПК.
*   [ ] **Глобальный веб-сервис:** Запуск публичного сайта для скачивания треков прямо в браузере без необходимости устанавливать локальный софт.
*   [ ] **Система аккаунтов:** Разграничение доступа, хранение истории, настроек и шаблонов именования для каждого пользователя индивидуально.
*   [ ] **Редактор метаданных (ID3):** Возможность редактировать теги файлов (артист, название, обложка, жанр) прямо из веб-интерфейса.
*   [ ] **Автоматическое кодирование (Transcoding):** Перекодирование файлов (например, в Opus или AAC с нужным битрейтом) на лету для экономии места на портативных плеерах.
*   [ ] **Синхронизация по Wi-Fi:** Беспроводная синхронизация через ADB-over-Wi-Fi или собственный сетевой протокол без кабелей.
*   [ ] **Кастомизация веб-панели:** Смена тем оформления (светлая/тёмная) и гибкая настройка интерфейса.

## Отказ от ответственности за соевость
Другие стриминговые сервисы добавляться не будут. Я ими не пользуюсь, а подстраиваться под соевых додиков личинусов не планирую.
