## Мотивация
Стриминговые сервисы — это ебаная помойка с подписками и цензурой, а современные телефоны без 3.5mm jack — технологический проёб. Проект написан, чтобы выкачивать музыку в один клик и слушать её как человек на нормальном плеере (например, **Cayin N3 Ultra**).

Полный текст моих мыслей по этому поводу — [внизу страницы](#манифест).

## Как это работает

*   **Высокопроизводительный Rust Backend:** Использует асинхронные библиотеки `soundcloud-rs` и `yt-audio-downloader` для многопоточного скачивания музыки без троттлинга скорости, быстрого стриминга и автотегирования ID3-тегов.
*   **Два источника (SoundCloud и YouTube):** Полноценный поиск, прослушивание превью и скачивание треков и плейлистов с обеих платформ.
*   **Отображение прогресса в реальном времени:** Прогресс видно как в терминале (CLI), так и в веб-панели через WebSocket / SSE.
*   **Web Panel на Angular:** Удобный интерфейс с виртуальным скроллингом, нечетким поиском, дашбордом статистики и встроенным аудио-плеером.
*   **Синхронизация по ADB с Android-устройствами:** Автоматически отслеживает подключение телефонов/плееров по USB, сравнивает библиотеки и заливает музыку в каталоги по исполнителям.
*   **Один бинарник:** Всё упаковано в один самодостаточный исполняемый файл со встроенным фронтендом.

## Особенности проекта

*   **Многопоточная параллельная загрузка:**
    *   **SoundCloud**: Скачивание Progressive MP3 и HLS аудиопотоков.
    *   **YouTube**: Многопоточная загрузка параллельными чанками в обход троттлинга CDN YouTube с конвертацией в MP3, FLAC, Opus, WAV через FFmpeg.
*   **Синхронизация по ADB с Android-устройствами:** 
    *   Автоматически отслеживает подключение девайсов по USB в реальном времени.
    *   Сравнивает локальную библиотеку и музыку на телефоне. Закидывает новые треки и автоматически удаляет те, которые вы удалили на ПК.
    *   Создает удобную структуру папок по исполнителю: `[Каталог_Музыки]/[Исполнитель]/[Название_трека].mp3`.
    *   Очищает пустые директории исполнителей на девайсе после удаления музыки.
    *   Защита от одновременных запусков синхронизации для одного устройства (`SyncGuard`).
*   **Умный Watchdog (Демон автообновления):** Отслеживает папку с загрузками в фоне. Любые ручные изменения мгновенно обновляют базу данных и запускают синхронизацию.
*   **Резервные прокси (Fallback Proxies):** Поддержка пула резервных прокси с автоматическим racing-перебором для обхода геоблокировок.
*   **Полноценный Web-интерфейс на Angular:**
    *   **Дашборд:** Подробная статистика (всего треков, размер библиотеки, активные загрузки), график активности скачивания и диаграмма аудио-форматов.
    *   **Поиск по SoundCloud и YouTube:** Единый тулбар поиска с закругленными табами, скачивание в один клик и превью-стриминг.
    *   **Управление библиотекой:** 
        *   Сверхбыстрый виртуальный скроллинг (`@angular/cdk/scrolling`) для тысяч треков без просадок FPS.
        *   Нечеткий локальный поиск (`Fuse.js`) по названию и артисту.
        *   Сортировка по имени, артисту и дате добавления.
        *   Массовое выделение и пакетное удаление треков.
        *   Скачивание файлов обратно на ПК прямо через браузер.
*   **Встроенный плеер в веб-панели:**
    *   Слушайте скачанные треки или превью прямо в браузере.
    *   Интеграция с Media Session API (управление в шторке, на экране блокировки, системные горячие клавиши).
    *   Глобальный хоткей: пробел для паузы/воспроизведения.
    *   Режимы перемешивания (Shuffle) по Фишеру-Йетсу и логарифмическая громкость с сохранением в LocalStorage.
*   **База данных redb:** Встроенная key-value БД на чистом Rust для настроек, истории и кэша метаданных.
*   **Бэкапы и облачная синхронизация:** Экспорт/импорт снапшотов библиотеки локально, по URL и через WebDAV.

## Быстрый старт

**1. Через терминал (Linux):**
```bash
curl -L https://github.com/IVKLD/VortexDL/releases/latest/download/vortex-dl -o vortex-dl && chmod +x vortex-dl
```

**2. Руками:**
1. Перейдите в раздел [Releases](https://github.com/IVKLD/VortexDL/releases).
2. Скачайте бинарный файл `vortex-dl`.
3. Дайте файлу права на выполнение: `chmod +x vortex-dl`.
4. (Опционально) Перенесите файл в любую папку из вашего `$PATH` (например, `/usr/local/bin`).

---
*   Официально поддерживается **Linux**.

### NixOS & Nix Flakes

#### 1. Запуск напрямую через Flakes
```bash
nix run --refresh github:IVKLD/VortexDL -- --serve
```

#### 2. Оболочка разработки
```bash
nix develop
```

#### 3. Установка в профиль Nix
```bash
nix profile install github:IVKLD/VortexDL
```

## Использование

**Загрузка по ссылке (SoundCloud или YouTube):**
```bash
vortex-dl https://soundcloud.com/artist/track
vortex-dl https://www.youtube.com/watch?v=dQw4w9WgXcQ
```

**Запуск веб-интерфейса:**
```bash
vortex-dl --serve
```

**Указание папки для сохранения:**
```bash
vortex-dl [URL] --output /path/to/music
```

## Разработка

### Требования

*   **Rust** (2024 edition, stable)
*   **Node.js** (18+) и **Yarn**
*   **[Just](https://github.com/casey/just)** (таск-раннер)
*   **FFmpeg** (для конвертации аудио)

### Запуск в режиме разработки

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/IVKLD/VortexDL.git
   cd VortexDL
   ```
2. Установите зависимости:
   ```bash
   just install
   ```
3. Запустите компоненты:
   ```bash
   # Терминал 1: Бэкенд
   just backend

   # Терминал 2: Фронтенд
   just frontend
   ```
   *Веб-панель: `http://localhost:4200` | REST API: `http://localhost:3200/api`*

### Сборка релизного бинарника

Собрать единый оптимизированный бинарник со встроенным Angular фронтендом:
```bash
just dist
```

## Манифест

Этот проект написан потому, что современные стриминговые сервисы — это ебаная помойка, которая не даёт слушать музыку офлайн без блядской подписки. Возможность закешировать треки и слушать их без интернета теперь стоит денег, что само по себе маразм.

А ещё эти хуесосы из стримингов удаляют музыку по щелчку пальца просто потому, что она стала "неугодной" государству. Хоть это и претензия скорее к самому государству, стриминги прогибаются мгновенно. В итоге моя любимая песня может просто пропасть, потому что так решил какой-то дядя в кабинете.

Отдельно меня бомбит от того, что в телефонах за 100к+ рублей нет ебучего 3.5mm jack. Как мне подключать студийные наушники? Засунуть джек себе в жопу и пердеть музыкой? 

Хотя современный поп-кал ничем не отличается: "Я РОНЯЮ ЗАПАД У, Я РОНЯЮ АНУС У, Я СОСУ ХУЕЦ У". Даёшь свои нормальные наушники и плеер какому-нибудь долбоёбу, а он говорит, что разницы нет. ДА КОНЕЧНО НЕТ, ТЫ ЖЕ СЛУШАЕШЬ СРАНИНУ КАКОГО-ТО ДАУНА, КОТОРЫЙ 1) НЕ УМЕЕТ СВОДИТЬ 2) НЕ УМЕЕТ ПИСАТЬ 3) НЕ УМЕЕТ ЧИТАТЬ.

Bluetooth и TWS — это отдельный ад с задержками и невозможностью нормально подключиться к компу. Нахуя мне весь этот геморрой, если есть ебучий провод, который просто вставил И ОНО РАБОТАЕТ?

Да, можно использовать эти переходники с Type-C на 3.5mm jack, но пошли они нахуй — у меня сдох уже второй переходник, и я больше не собираюсь терпеть этот технологический проёб от корпораций. Кушайте дальше говно про то, что порт только для зарядки, хотя с телефона можно выводить видео, и это малая часть того, что мы потеряем.

Я устал это терпеть. Я решил показать яйца — и вот они. Пусть маленькие, но зато свои.

В итоге я купил себе пиздатый плеер **Cayin N3 Ultra** и написал эту хуйню, чтобы выкачивать всё из SoundCloud и YouTube в один клик, автоматически синхронизировать на девайс по ADB при подключении по проводу и слушать музыку как человек, а не как жертва маркетинга.
