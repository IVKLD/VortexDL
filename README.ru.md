## Мотивация
Стриминговые сервисы — это ебаная помойка с подписками и цензурой, а современные телефоны без 3.5mm jack — технологический проёб. Проект написан, чтобы выкачивать музыку в один клик и слушать её как человек на нормальном плеере (например, **Cayin N3 Ultra**).

Полный текст моих мыслей по этому поводу — [внизу страницы](#манифест).

## Как это работает

*   **Rust Backend:** Делает всю основную работу. Использует библиотеку `soundcloud-rs` для доступа к API и качает музыку в несколько потоков, чтобы не ждать вечность.
*   **Отображение прогресса:** Прогресс скачивания видно везде: и в консоли (CLI), и в веб-панели. Так что всегда понятно, сколько ещё осталось.
*   **Web Panel:** Веб-интерфейс на Angular для тех, кому в падлу юзать консоль. Просто вставил ссылку и всё наглядно.
*   **Один бинарник:** Всё упаковано в один файл, так что не надо ебаться с установкой кучи либ и зависимостей.

## Особенности проекта

*   **Многопоточная параллельная загрузка:** Быстро скачивает музыку с SoundCloud в несколько потоков (настраивается в лимитах).
*   **Синхронизация по ADB с Android-устройствами:** 
    *   Автоматически отслеживает подключение девайсов по USB в реальном времени.
    *   Сравнивает локальную библиотеку и музыку на телефоне. Закидывает новые треки и автоматически удаляет те, которые вы удалили на ПК.
    *   Создает удобную структуру папок по исполнителю: `[Каталог_Музыки]/[Исполнитель]/[Название_трека].mp3`.
    *   Очищает пустые директории исполнителей на девайсе после удаления музыки.
    *   Защита от одновременных запусков синхронизации для одного устройства (`SyncGuard`).
*   **Умный Watchdog (Демон автообновления):** Отслеживает папку с загрузками в фоне. Если добавить или удалить файлы вручную, бэкенд мгновенно переиндексирует библиотеку и запустит синхронизацию с подключенными по ADB телефонами.
*   **Резервные прокси (Fallback Proxies):** Настройка основных и списка резервных прокси для обхода блокировок SoundCloud. При ошибках скачивания загрузчик перебирает доступные прокси.
*   **Полноценный Web-интерфейс на Angular:**
    *   **Дашборд:** Подробная статистика (всего треков, общий размер библиотеки, активные загрузки), график активности скачивания за последние 7 дней и круговая диаграмма аудио-форматов (MP3, FLAC, WAV).
    *   **Поиск по SoundCloud:** Удобный поиск музыки, скачивание в один клик и прослушивание превью трека прямо в браузере.
    *   **Управление библиотекой:** 
        *   Сверхбыстрый виртуальный список с поддержкой тысяч треков без тормозов браузера (`Virtual Scrolling`).
        *   Умный локальный нечеткий поиск (Fuzzy Search через `Fuse.js`) по названию и артисту.
        *   Сортировка по имени, дате добавления.
        *   Выделение нескольких треков для массового удаления.
        *   Возможность скачать любой файл из библиотеки обратно на ПК через браузер.
*   **Встроенный плеер в веб-панели:**
    *   Позволяет слушать скачанные треки или превью прямо в браузере.
    *   Поддержка управления воспроизведением в фоне с помощью системных клавиш и Media Session API (отображение обложки, автора и названия на экране блокировки/в системной шторке).
    *   Глобальный хоткей: пробел для паузы/воспроизведения.
    *   Режимы перемешивания (Shuffle) на базе алгоритма Фишера-Йетса и регулировка громкости (с сохранением состояния в LocalStorage).
*   **База данных redb:** Легковесная embedded БД на Rust для хранения настроек, истории синхронизаций и кеша треков. Никаких внешних серверов баз данных разворачивать не нужно.

## Быстрый старт

**1. Через терминал (Linux):**
```bash
curl -L https://github.com/IVKLD/VortexDL/releases/latest/download/vortex-dl -o vortex-dl && chmod +x vortex-dl
```

**2. Руками:**
1. Перейдите в раздел [Releases](https://github.com/IVKLD/VortexDL/releases).
2. Скачайте бинарный файл `vortex-dl`.
3. Дайте файлу права на выполнение: `chmod +x vortex-dl`.
4. (Опционально) Перенесите файл в любую папку из вашего `$PATH` (например, `/usr/local/bin`), чтобы команду можно было запускать отовсюду.

---
*   На данный момент официально поддерживается только **Linux**.
*   Насчет **macOS** и **Windows**: я не программист и хз, как там у маководов и виндузятников всё устроено. В теории должно работать. Если очень надо — пишите Issue, буду пробовать фиксить или ждать контрибьюторов.

## Разбор ошибок

### "No available download options"
Если вылезла эта ошибка, то скорее всего:
1.  У вас херовый прокси или VPN. SoundCloud просто блочит скачивание для вашего региона. Лучше юзать нормальные резидентские IP.
2.  Песню реально нельзя скачать. Бывает такая дичь со стороны SoundCloud, но редко. Обычно всё упирается в первый пункт.

## Использование

**Загрузка по ссылке:**
```bash
vortex-dl https://soundcloud.com/artist/track
```

**Запуск веб-интерфейса:**
```bash
vortex-dl --serve
```

**Указание папки для сохранения:**
```bash
vortex-dl [URL] --output /path/to/music
```

## Разработка

### Требования

Для разработки и сборки требуется одно из следующего:

*   **Devbox (Nix):** Рекомендуемый метод. Все зависимости изолированы.
*   **Ручная установка:**
    *   Rust (stable toolchain)
    *   Node.js (18+) и Yarn
    *   [Just](https://github.com/casey/just) (утилита для запуска команд сборки и разработки)

### Начало работы

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/IVKLD/VortexDL.git
   cd VortexDL
   ```
2. Установите зависимости бэкенда и фронтенда одной командой:
   ```bash
   just install
   ```
3. Запустите компоненты для разработки:
   ```bash
   # Терминал 1: Бэкенд (запустится в режиме автоматического перезапуска при изменении кода)
   just backend

   # Терминал 2: Фронтенд
   just frontend
   ```
   *Web Panel (frontend) будет доступна по адресу http://localhost:4200. REST API бэкенда по умолчанию доступен на http://localhost:3200/api.*


Подробности о структуре проекта и технической реализации можно найти в файле [Development.ru.md](Development.ru.md).

## Сборка

Для создания полноценного оптимизированного бинарного файла со встроенным веб-интерфейсом:
```bash
just dist
```

Для сборки только бэкенда (без веб-интерфейса):
```bash
just build
```

## Манифест

Проект написан, потому что современные стриминговые сервисы — это ебаная помойка, которая не даёт слушать музыку без интернета без ебаной подписки. Возможность закешировать треки и слушать их в офлайне теперь стоит денег, что просто пиздец. 

И ещё эти пидорасы из стримингов по щелчку пальцев удаляют музыку, которая стала "неугодной" правительствам. Хотя это больше доёб к правительствам, но стриминги ложатся под них на раз-два. В итоге моя любимая песня может просто исчезнуть, потому что какой-то дядя в кабинете так решил.

Ещё меня максимально вымораживает, что в телефонах за 100к+ больше нет ебаного 3.5mm jack. Как мне, блять, студийные наушники подключать? Джеком в жопу себе вставлять и наперживать музло? 

Хотя от современного говна попсового никак это не отличается Я РОНЯЮ ЗАПАД У, Я РОНЯЮ АНУС У, Я СОСУ ХУЙ У. Даёшь потом попробовать свои норм наушники и плеер додику, а он говорит, что разницы нет. БЛЯТЬ ЕЁ И НЕ БУДЕТ, ТАК КАК ТЫ ГОВНО СЛУШАЕШЬ, ЕБЛАНА, КОТОРЫЙ 1) СВОДИТЬ НЕ УМЕЕТ 2) ПИСАТЬ 3) ЧИТАТЬ.

Bluetooth и TWS — это отдельный вид секса с задержками и невозможностью нормально подключиться к компу. Нахуя мне всё это, если есть ебаный провод, который просто вставил И ОНО РАБОТАЕТ?

Да, можно юзать переходники с usb type-c на круглого ебаната 3.5, но блять, у меня уже второй переходник умер и терпеть такой технологический проёб от корпораций я не собираюсь. А вы дальше жрите своё говно, что у вас этот порт только для зарядки, хотя можно и видео выводит с телефона и это только малая часть того андрея, что мы проебём скоро. 

Терпеть я не стал, и решил показать яйца - показываю. Да, маленькие, но зато настоящие.

В итоге я купил себе ахуенный плеер **Cayin N3 Ultra** и написал эту хуиту, чтобы выкачивать всё из SoundCloud в один клик, закидывать по проводу и слушать музыку как человек, а не как жертва маркетинга.
